# 📝 Todo App

This is a simple and user-friendly Todo App built using HTML, CSS, and Vanilla JavaScript. It allows users to manage their daily tasks by adding, editing, deleting, and marking tasks as completed. The application uses Local Storage to save tasks, so they remain available even after refreshing or closing the browser.

I built this project to strengthen my JavaScript fundamentals and gain hands-on experience with DOM manipulation, event handling, objects, arrays, functions, and Local Storage.

---

## ✨ Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* 🗑️ Delete tasks
* ✅ Mark tasks as completed
* 💾 Save tasks using Local Storage
* 🔄 Automatically load saved tasks after refreshing the page
* 🔍 Filter tasks (All / Completed / Pending)
* ⌨️ Add tasks by pressing the **Enter** key
* 📱 Clean and responsive user interface
